# 프로젝트 로드맵

> Discord 명령 기반 AI 개발팀 운영 템플릿을 단계적으로 구축한다.

## 문서의 목적

이 문서는 무엇을 먼저 만들고, 무엇을 나중에 만들지를 정한다. 로드맵이 있어야 실험이 프로젝트가 되고, 프로젝트가 문서와 운영으로 남는다.

## 최종 비전

Hermes Agent Lab은 Discord를 중심 인터페이스로 사용해, 요청 접수 → 역할 배정 → 실행 → 검토 → 기록까지 이어지는 AI 개발팀 운영 템플릿이 된다.

핵심 문장:
> 이 프로젝트의 성공은 더 많은 기능이 아니라, 더 적은 혼란으로 같은 작업을 반복할 수 있는가로 판단한다.

## 단계별 로드맵

### Phase 0. 방향 정리

목표:
- 프로젝트 목표를 한 문장으로 고정한다.
- 역할과 용어를 통일한다.
- Discord에서 어떤 명령을 표준으로 쓸지 정한다.

산출물:
- README 초안
- 역할 정의서
- 워크플로우 초안

종료 기준:
- 핵심 문서 4개가 서로 같은 용어를 쓴다.
- 최소 역할과 확장 역할이 구분된다.

핵심 문장:
> 첫 단계의 목적은 구현이 아니라, 모두가 같은 말을 쓰게 만드는 것이다.

### Phase 1. 최소 실행 템플릿

목표:
- 첫 번째 실제 작업을 실행할 수 있는 최소 문서를 만든다.
- 요청/계획/실행/검토/완료의 기본 순서를 확정한다.
- 담당자와 기록 방식이 일관되게 보이도록 만든다.

산출물:
- `docs/first-task.md`
- 명령 템플릿
- 완료 보고 템플릿

종료 기준:
- Discord 명령 예시가 한 번의 실행 흐름으로 이어진다.
- 검토 단계가 반드시 포함된다.
- 결과가 기록 형식으로 남는다.

핵심 문장:
> 템플릿은 완벽해야 하는 것이 아니라, 한 번 실제로 돌아가야 한다.

### Phase 2. 협업 구조 안정화

목표:
- 역할별 책임과 권한을 분리한다.
- 중간 검토와 재작업 기준을 넣는다.
- 작업 이력과 결정 로그를 남긴다.

산출물:
- 역할별 핸드오프 규칙
- 검토 체크리스트
- 운영 기록 양식

종료 기준:
- 동일한 입력에 대해 비슷한 결과가 재현된다.
- 실패 사유와 재시도 기준이 문서화된다.

핵심 문장:
> 협업 구조가 안정되면, 사람 대신 시스템이 맥락을 유지할 수 있다.

### Phase 3. 자동화 확장

목표:
- 반복 작업을 명령이나 템플릿으로 묶는다.
- 상태 갱신과 보고를 자동화한다.
- 필요하면 후속 작업을 연결한다.

산출물:
- 자동 응답 규칙
- 상태 업데이트 규칙
- 반복 작업 템플릿

종료 기준:
- 반복되는 요청이 같은 방식으로 처리된다.
- 상태 변경과 보고가 자동 또는 반자동으로 남는다.

핵심 문장:
> 자동화는 편의 기능이 아니라, 운영 일관성을 지키는 수단이다.

### Phase 4. 운영 템플릿화

목표:
- 문서를 실제 운영 표준으로 고정한다.
- 새 구성원이 들어와도 같은 방식으로 시작할 수 있게 만든다.
- 실패 사례와 개선점을 반영해 버전을 올린다.

산출물:
- 운영 가이드
- 신규 참여자 온보딩 문서
- 개선 이력

종료 기준:
- 새 작업을 시작할 때 다시 설명할 내용이 거의 없다.
- 문서만 보고도 기본 운영이 재현된다.

핵심 문장:
> 최종 목표는 멋진 데모가 아니라, 반복 가능한 운영 방식이다.

## 우선순위 기준

우선순위는 다음 기준으로 정한다.

1. 운영에 꼭 필요한가
2. 첫 번째 실제 과제에 필요한가
3. 반복 사용될 가능성이 높은가
4. 나중에 고치기 어려운가

핵심 문장:
> 먼저 해결할 것은 가장 화려한 기능이 아니라, 가장 자주 막히는 부분이다.

## 리스크

- 역할이 너무 많아져서 복잡해질 수 있다.
- 명령이 많아져 사용성이 떨어질 수 있다.
- 문서가 늘어나도 실제 운영이 따라오지 않을 수 있다.
- 검토 기준이 느슨하면 템플릿이 금방 무너진다.

핵심 문장:
> 로드맵은 기능 목록이 아니라, 복잡도를 통제하는 장치여야 한다.

## 성공 지표

- Discord 명령으로 첫 작업을 끝까지 운영할 수 있다.
- 역할과 흐름이 문서만 보고도 재현된다.
- 검토 기준이 명확하고 반복 가능하다.
- 새 작업이 와도 같은 틀로 처리된다.
